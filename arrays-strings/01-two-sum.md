# Two Sum

**LeetCode:** https://leetcode.com/problems/two-sum/

**Language:** C

## Approach

I used a brute-force approach with two nested loops. The first loop selects an element, and the second loop checks the remaining elements to find a pair whose sum equals the target.

## Time Complexity

O(n²) – Two nested loops are used.

## Space Complexity

O(1) – No additional data structure is used.
